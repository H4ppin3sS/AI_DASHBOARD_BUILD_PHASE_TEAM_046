# Tài liệu gốc

- `Algorithms_Formulas.md`: thuật toán và công thức.
- `Algorithms_Formulas.docx`: bản Word thuật toán/công thức.
- `Metrics_Thresholds.md`: metrics và cách đặt ngưỡng.

Ba file được sao chép nguyên byte. Các tính năng Coverage và Scene Finder phát triển sau đó có thể chưa được phản ánh trong tài liệu gốc.
